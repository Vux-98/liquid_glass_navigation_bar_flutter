# Changelog

## 1.1.0

* Initial release.
* `LiquidGlassNavWidget` — glassmorphism bottom navigation bar with animated sliding indicator.
* `LiquidGlassNavTheme` — light, dark, and fully custom presets.
* `LiquidGlassNavItem` — navigation item with optional selected icon and badge count.
* `LiquidGlassNavAction` — optional floating action chip above the bar.
* Tablet/responsive layout support (auto-detected or via `isTablet`).
* Optional custom font family via `LiquidGlassNavTheme.fontFamily`.
